# Meeting Prep

## When to Use
Activate when:
- User asks to prepare for a meeting
- Calendar event is approaching (30-minute warning)
- User sends meeting invite or agenda

## Procedure

### Step 1: Gather Meeting Context
1. Get meeting details from calendar (title, time, participants, description)
2. Search email/chat history for related conversations
3. Check for any previous meetings with same participants

### Step 2: Research Participants
1. Look up participant profiles from memory
2. Note any pending action items with them
3. Check their recent activity/projects if relevant

### Step 3: Prepare Materials
```
## Meeting Prep: [Meeting Title]
📅 [Date] at [Time] ([Duration])
👥 [Participant list]

### Agenda
1. [Topic from meeting description]
2. [Inferred topic from recent conversations]
3. [Open items from last meeting]

### Context
- [Relevant background information]
- [Recent developments]

### Your Talking Points
- [Key point to raise]
- [Question to ask]
- [Update to share]

### Action Items (from previous meetings)
- [ ] [Pending item]
- [x] [Completed item to report]
```
