# Raven Gap Plan — Hermes-Level Features

## Phase 1: Critical Fixes

### 1.1 Fix MemoryFacade Async Bug
**File:** `app/core/memory_facade.py`
**Issue:** `recall()` deadlocks event loop via `pool.submit(asyncio.run, ...).result()`
**Fix:** Use `asyncio.run_coroutine_threadsafe()` with separate wait executor

### 1.2 Fix Provider Fallback Chain
**Files:** `app/core/runtime.py`, `app/core/model_router.py`
**Issue:** Tries 6+ providers before finding one that works
**Fix:** Max 3 attempts + health check CLI providers

### 1.3 Wire CorrectionLearner Into Runtime
**File:** `app/core/runtime.py`
**Issue:** `process_correction()` exists but isn't called
**Fix:** Call in `_learn_from_turn()` after every response
